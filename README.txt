노원구 생활인구 기반 대중교통 접근성 · 웹GIS 배포 안내
====================================================

1. 이 폴더의 index.html을 더블클릭하면 웹지도가 열립니다.
   지도 라이브러리 Leaflet을 불러오려면 인터넷이 필요합니다.
   기본적으로 OpenStreetMap 배경지도는 꺼져 있습니다. (403 오류 방지)

2. GitHub Pages 배포:
   (1) GitHub에 공개 저장소 nowon-transit-webgis 를 만듭니다.
   (2) 이 webmap 폴더 안의 index.html 과 metadata.json 을 저장소 최상위(root)에 업로드합니다.
   (3) 저장소 Settings → Pages → Deploy from a branch → main / (root) → Save.
   (4) 배포된 주소는 보통 https://아이디.github.io/nowon-transit-webgis/ 입니다.
       실제 주소는 GitHub Pages 화면에 나온 것을 사용하세요.

3. 기능:
   기준안 및 대안 3개 전환, MCDA 순위, 상위 후보 10개 탐색,
   격자 ID 검색, 생활인구 및 정류장·지하철역 거리 팝업,
   범례, 축척, 반응형 레이아웃. 배경지도는 선택적으로 켭니다.

4. 데이터 한계:
   2026-10-16 하루의 내국인 추정 생활인구를 사용했고 비식별화된 값은 제외.
   격자 중심점-최근접 시설 간 직선거리(실제 보행거리/운행시간 아님).
   후보지역 점수는 가중치 기반 상대순위로 실제 시설 설치 적합성을 보장하지 않음.
   기준안 등 시나리오 정의와 MCDA 재현 코드는 nowon_step11_mcda_auto.py 를 참고.

5. 검증:
   웹지도 총 격자 수와 평가 가능 격자 수가 콘솔 결과(457 / 419)와 같은지 확인.
   시나리오별 후보 수는 기준안 107, s1 115, s2 143, s3 151 개가 기대값.
   기준안 상위 격자 다사62556500의 점수 약 54.5908을 팝업에서 확인.
